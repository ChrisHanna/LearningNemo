WHY BOTH SAW AND OPENSHELL?

An identity is not
an isolation boundary.

Authentication establishes the caller. It does not contain a script, restrict an outbound connection, or stop a process from reading a file.

The managed envelope around the website agent's private Azure VM: lifecycle, perimeter, trusted services, and audit.
OpenShell
The inner execution boundary: non-root MicroVM processes and narrow filesystem/network policies.
Guardrails
Inspect inputs before model/tool use. Content screening complements, but cannot replace, permissions and isolation.
